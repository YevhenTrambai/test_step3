# crm-tat-mcp — MCP-интеграция с CRM туроператоров TAT.ua

Инструмент, который позволяет задавать критерии поиска туров (**цена, даты, страны,
туроператоры**) прямо в чате Claude и получать целевые результаты **плюс аналитику**
(сравнение по операторам, динамика цен, тренды, мониторинг изменений) из агентской
CRM **crm.tat.ua/tf**.

Под капотом: Playwright логинится вашим логином/паролем и держит сессию; запросы идут
либо через найденный внутренний JSON API CRM, либо через перехват трафика SPA; история
результатов пишется в локальный SQLite для динамики и мониторинга; всё это обёрнуто в
MCP-сервер с инструментами, которые вызывает Claude.

> ⚠️ Работает **локально** под вашим собственным авторизованным аккаунтом. Секреты живут
> только в `.env` (в `.gitignore`) и никуда не отправляются. Сайт под bot-защитой —
> поэтому используется реальный браузер (Playwright), а не «голый» fetch.

## Установка

```bash
cd crm-mcp
npm install
npx playwright install chromium   # если Chromium ещё не стоит
cp .env.example .env              # впишите CRM_LOGIN и CRM_PASSWORD
```

## Шаг 1 — Разведка API (обязательно, один раз)

Внутренний API CRM заранее неизвестен, поэтому сначала надо его «снять»:

```bash
CRM_HEADFUL=true npm run recon
```

Откроется браузер с вашей сессией. Залогиньтесь (если надо), **выполните любой поиск тура**
(страна, даты), вернитесь в терминал и нажмите ENTER. Скрипт сохранит:

- `recon-dumps/network-full.json` — весь перехваченный трафик;
- `recon-dumps/api-candidates.json` — отфильтрованные JSON/API-вызовы (это и есть поиск/справочники).

Посмотрите `api-candidates.json` и впишите в `.env` найденные значения:

```ini
CRM_CLIENT_MODE=api              # переключиться на прямые вызовы (быстрее), либо оставить intercept
CRM_SEARCH_API=/tf/api/...       # эндпоинт поиска из дампа
CRM_REFERENCE_API=/tf/api/...    # эндпоинт справочников
CRM_SEARCH_MATCH=search,tour     # подстроки URL результатов (для intercept-режима)
```

Селекторы формы (для intercept-режима) и маппинг полей ответа правятся в `src/config.js`
и функции `normalizeOffers` в `src/search.js` — это **единственные** места с привязкой к
конкретной верстке/схеме CRM.

## Шаг 2 — Проверка из CLI

```bash
node scripts/search-cli.js '{"countries":["Єгипет"],"dateFrom":"2026-07-10","priceMax":45000}'
```

Должен вернуть найденные офферы и сравнение по операторам. Сверьте 2–3 цены с UI вручную.

## Шаг 3 — Подключение к Claude Code

Добавьте сервер в конфиг MCP (например `.mcp.json` проекта):

```json
{
  "mcpServers": {
    "crm-tat": {
      "command": "node",
      "args": ["crm-mcp/src/mcp-server.js"],
      "cwd": "/абсолютный/путь/к/test_step3"
    }
  }
}
```

или через CLI:

```bash
claude mcp add crm-tat -- node /абсолютный/путь/crm-mcp/src/mcp-server.js
```

После этого можно писать в чате критерии — Claude вызовет инструменты.

## Инструменты MCP

| Инструмент | Назначение |
|---|---|
| `crm_list_reference` | Доступные страны, туроператоры, города вылета, типы питания |
| `crm_search_tours` | Поиск по критериям → нормализованные офферы (+ снэпшот в историю) |
| `crm_compare_operators` | Сравнение по операторам: кол-во, мин/средняя/медианная цена, лучший оффер |
| `crm_price_dynamics` | Распределение цен по датам вылета + тренд мин-цены по истории |
| `crm_monitor_diff` | Что изменилось с прошлого снэпшота: новые / ушедшие / подешевевшие / подорожавшие |

Критерии (для поисковых инструментов): `countries[]`, `operators[]`, `dateFrom`,
`dateTo`, `priceMin`, `priceMax`, `nights`, `nightsTo`, `adults`, `children`, `boards[]`,
`stars`, `departure`.

## Структура

```
src/config.js     # вся конфигурация + привязка к CRM (эндпоинты/селекторы)
src/auth.js       # Playwright-логин и кеш сессии
src/client.js     # api-режим (прямые вызовы) и intercept-режим (перехват SPA)
src/reference.js  # справочники + маппинг имён в id
src/search.js     # параметризованный поиск + нормализация офферов
src/store.js      # SQLite-история снэпшотов
src/analytics.js  # сравнение, динамика, тренды, дифф (чистые функции)
src/mcp-server.js # MCP stdio-сервер с 5 инструментами
scripts/recon.js  # разведка внутреннего API
```

## Обслуживание

Если CRM меняет фронтенд/API и поиск ломается — повторите `npm run recon` и обновите
эндпоинты/селекторы в `src/config.js`. Бизнес-логика и аналитика при этом не меняются.
